# Prompts used with the coding agent (Claude Code)

**Platform:** neither VS Code nor Antigravity. Claude Code v2.1.283 (Anthropic's agentic coding CLI, model Opus 5.5,
auto permission mode) was run in the Ubuntu terminal of the execution machine, from the project folder. Design, the
step-by-step pipeline, agent and API, all diagnosis and independent verification were done with the Claude chat assistant.

Each task was given as a written brief (full text in the linked file) plus one instruction typed at the Claude Code prompt.

|---|---|---|

When done, report the files you changed, the full pytest output, and the consolidated results table. |
